# Flood Fighting: ทางเลือกซ่อมกำแพงริมคลอง

ภาพตัดขวาง 3D (three.js) อธิบายปัญหาน้ำซึมผ่านกำแพงและน้ำลอดใต้ฐานราก (underseepage / sand boil) และวิธีแก้ไขแต่ละแบบ

| แท็บ | วิธี |
|---|---|
| ! | สภาพปัญหา: น้ำซึมผ่านรอยร้าวและลอดใต้ฐาน |
| 0 | มาตรการเร่งด่วน: วงกระสอบทราย รางระบายชั่วคราว วาล์วกันน้ำย้อน |
| A | อัดฉีด PU/Epoxy และอุดรอยร้าว |
| B | ระบบระบายน้ำใต้ดิน (French drain) พร้อมบ่อสูบ |
| C | เข็มพืดกันซึม (Sheet pile) |
| D | ม่านอัดฉีดใต้ดิน (Jet grouting) |
| E | กำแพง คสล. ใหม่ |

แต่ละวิธีมีขั้นตอนหลัก ราคาโดยประมาณต่อเมตร มาตรฐานและคู่มืออ้างอิง (USACE, ACI, EN, FHWA, มอก.) และลิงก์ตัวอย่างวัสดุ

ราคาเป็นค่าประมาณสำหรับตั้งกรอบงบประมาณ ชั้นดินในภาพเป็นการสมมติเพื่ออธิบาย วิธีและความลึกที่ใช้จริงต้องให้วิศวกรที่มีใบอนุญาตกำหนดจากผลเจาะสำรวจดิน
